# AcornAtlanta

## Calculator App

This project contains a basic calculator web app built with Python's standard library.

### Run the app

From the project directory, start the server:

```bash
cd /Users/kennyrhee/Desktop/workspace/git/AcornAtlanta
python3 app.py
```

Then open this in your browser:

```text
http://localhost:8001
```

### Use the calculator

1. Enter a value in the first number field.
2. Choose an operation:
   - Addition (+)
   - Subtraction (-)
   - Multiplication (×)
   - Division (÷)
3. Enter a value in the second number field.
4. Click "Calculate".
5. The result will appear below the form.

### Notes

- Division by zero shows an error message.
- Invalid input also shows an error message.
- The app runs on port 8001 by default.
